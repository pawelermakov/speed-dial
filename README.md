# SpeedDial X

![Логотип SpeedDial X](public/images/icon128.png)

Визуальные закладки и удобная новая вкладка для **Google Chrome и Mozilla Firefox**.

[Установка в Chrome](#chrome) · [Установка в Firefox](#firefox) · [Возможности](#возможности) · [Настройки](#настройки)

## Возможности

- **Три языка интерфейса** — Русский, English и Español. По умолчанию используется русский язык.

- **Закладки и папки** — добавление, редактирование, удаление, перенос и сортировка перетаскиванием. Все изменения сохраняются в закладках браузера.
- **Визуальные плитки** — эскизы сайтов, иконки и цветные заглушки с доменом. Эскизы можно создавать и обновлять вручную.
- **Единый поиск** — Яндекс, Google и поиск по названию или адресу закладки, с подсказками и переключением источника.
- **Фильмы и сериалы** — дополнительный поиск через Кинопоиск, IMDb и MyShows.
- **Своё оформление** — светлая, тёмная и системная темы, собственный фон, настройка сетки и вертикальное центрирование закладок.
- **Почта** — отдельные счётчики непрочитанных Mail.ru, Gmail и Яндекс Почты без ручного ввода адреса.
- **Погода** — ссылка на прогноз Яндекс Погоды или Gismeteo для одного из 16 городов-миллионников России.
- **Резервные копии** — выборочный импорт и экспорт закладок, папок, изображений, настроек и фона в JSON.
- **Клавиатура и доступность** — навигация, контекстные меню и диалоги с поддержкой клавиатуры, уменьшения движения и повышенной контрастности.

## Установка

Поддерживаются **Google Chrome** и **Mozilla Firefox 140+**. Для сборки из исходников нужны **Node.js 22.12+** и **npm 10+**.

Скачайте исходники и установите зависимости в папке проекта:

```sh
npm ci
```

### Chrome

```sh
npm run build
```

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите `.output/chrome-mv3`.

### Firefox

```sh
npm run build:firefox
```

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите файл `.output/firefox-mv2/manifest.json`.

Это временная установка для разработки. Для постоянной установки Firefox требуется подписанное дополнение.

## Настройки

Откройте шестерёнку на новой вкладке. Все изменения сохраняются автоматически.

| Настройка | Доступные варианты | По умолчанию |
| --- | --- | --- |
| Язык | Русский, English, Español | Язык браузера; иначе English |
| Папка закладок | Папка браузера, из которой показываются закладки | «Другие закладки», если доступны |
| Тема | Системная, светлая, тёмная | Системная |
| Фон | Собственное изображение или без фона | Без изображения |
| Кнопка добавления закладки | Плитка «+» | Выключена |
| Поиск по закладкам | Пункт «Закладки» в общем поиске | Включён |
| Поиск фильмов и сериалов | Кинопоиск, IMDb, MyShows | Выключен |
| Поисковая система | Выбирается в строке поиска | Яндекс |
| Ширина сетки | 50–100% | 100% |
| Количество столбцов | 2–12; на узких экранах число уменьшается | 6 |
| Расстояние между плитками | 0–48 px | 24 px |
| Центрировать по вертикали | Центрирование только закладок | Выключено |
| Почта | Отдельное включение Mail.ru, Gmail и Яндекс Почты | Все выключены |
| Виджет погоды | Ссылка на прогноз | Выключен |
| Город | 16 городов-миллионников России | Москва |
| Сервис погоды | Яндекс Погода, Gismeteo | Яндекс Погода |

**Синхронизация** показывает доступный статус браузерной синхронизации и действия с настройками. **Данные → Управление данными** позволяет импортировать, экспортировать или сбросить настройки, фон и локальные изображения. Сброс не удаляет закладки браузера.

## Полезно знать

- **Управление:** правый клик открывает действия с плитками и папками; перетаскивание меняет порядок. Поиск и панель папок остаются на виду при прокрутке закладок.
- **Клавиши:** `/` открывает поиск по закладкам, стрелки перемещают фокус или выделение, `Enter` подтверждает действие, `Escape` закрывает подсказки и диалоги.
- **Язык:** переключается сразу и сохраняется вместе с настройками. Описание в списке расширений локализуется по языку браузера.
- **Почта:** нужно войти в сервис в том же профиле браузера. Gmail использует первый аккаунт, Mail.ru и Яндекс — текущий. Число проверяется при открытии вкладки и включении сервиса; при ошибке пояснение доступно в подсказке.
- **Погода:** карточка открывает прогноз на сайте сервиса; текущая температура на новой вкладке не отображается.
- **Эскизы:** для создания скриншота расширение временно открывает сайт в активной вкладке.

## Данные и приватность

- Закладки хранятся в браузере; настройки используют хранилище расширения и браузерную синхронизацию.
- Эскизы, иконки и фон остаются локальными. Для переноса на другое устройство используйте JSON-копию.
- Поисковые запросы отправляются выбранному поисковому сервису, проверки почты — соответствующему почтовому сервису.
- Собственного сервера нет. Расширение не сохраняет пароли, cookies и почтовые токены.

## Разработка

**Vue 3 · TypeScript · WXT · Tailwind CSS 4 · Dexie**

Переводы интерфейса и описания расширения хранятся в `locales/ru.json`, `locales/en.json` и `locales/es.json`. Все файлы используют одинаковые плоские ключи.

| Команда | Назначение |
