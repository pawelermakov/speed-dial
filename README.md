# SpeedDial X

![Логотип SpeedDial X](public/images/icon128.png)

Ваши закладки **Google Chrome и Mozilla Firefox** в виде удобных визуальных плиток на новой вкладке. SpeedDial X работает напрямую с закладками браузера, сохраняя привычные папки и синхронизацию между устройствами.

[Возможности](#возможности) · [Установка](#установка) · [Приватность](#данные-и-приватность) · [Разработка](#разработка)

## Возможности

- **Языки интерфейса** — Русский, English и Español.
- **Закладки и папки** — добавление, редактирование, удаление, перенос и сортировка перетаскиванием.
- **Визуальные плитки** — эскизы сайтов, иконки и цветные заглушки с доменом. Эскизы можно создавать и обновлять вручную.
- **Поиск** — по названию или адресу закладки, в Яндексе и Google, а также в Кинопоиске, IMDb и MyShows, с подсказками и переключением источника.
- **Своё оформление** — светлая, тёмная и системная темы, собственный фон, настройка сетки и вертикальное центрирование закладок.
- **Почта** — счётчики непрочитанных Mail.ru, Gmail и Яндекс Почты.
- **Погода** — ссылка на прогноз Яндекс Погоды или Gismeteo для одного из 16 городов-миллионников России.
- **Резервные копии** — выборочный импорт и экспорт закладок, папок, изображений, настроек и фона в JSON.
- **Клавиатура и доступность** — навигация, контекстные меню и диалоги с поддержкой клавиатуры, уменьшения движения и повышенной контрастности.

## Установка

Поддерживаются **Google Chrome** и **Mozilla Firefox 140+**. Для сборки из исходников нужны **Node.js 22.12+** и **npm 10+**.

### Сборка из исходников

Клонируйте репозиторий и установите зависимости:

```sh
git clone https://github.com/pawelermakov/speed-dial.git
cd speed-dial
npm ci
```

### Chrome

```sh
npm run build
```

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите `.output/chrome-mv3`.

### Firefox

```sh
npm run build:firefox
```

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите файл `.output/firefox-mv2/manifest.json`.

Это временная установка для разработки. Для постоянной установки Firefox требуется подписанное дополнение.

## Особенности и ограничения

- **Клавиши:** `/` открывает поиск по закладкам, `Escape` закрывает подсказки и диалоги.
- **Почта:** нужно войти в сервис в том же профиле браузера. Gmail использует первый аккаунт, Mail.ru и Яндекс — текущий. Число проверяется при открытии вкладки и включении сервиса; при ошибке пояснение доступно в подсказке.
- **Эскизы:** для создания скриншота расширение временно открывает сайт в активной вкладке.
- **Настройки:** сохраняются автоматически. Сброс через **Данные → Управление данными** не удаляет закладки браузера.

## Данные и приватность

- Закладки хранятся в браузере; настройки используют хранилище расширения и браузерную синхронизацию.
- Эскизы, иконки и фон остаются локальными. Для переноса на другое устройство используйте JSON-копию.
- При получении поисковых подсказок введённый текст отправляется соответствующему поисковому сервису; при переходе к результатам запрос открывается на его сайте. Поиск по закладкам выполняется локально.
- Проверки почты обращаются к соответствующему почтовому сервису. Загрузка иконок может обращаться к сайтам закладок; создание эскиза открывает сам сайт.
- Собственного сервера нет. Расширение не сохраняет пароли, cookies и почтовые токены.

## Разработка

**Vue 3 · TypeScript · WXT · Tailwind CSS 4 · Dexie**

Переводы интерфейса и описания расширения хранятся в `locales/ru.json`, `locales/en.json` и `locales/es.json`. При изменении текстов обновляйте все три файла, сохраняя одинаковые ключи.

### Команды сборки и проверки

| Команда | Назначение |
| --- | --- |
| `npm run dev` / `npm run dev:firefox` | Разработка для Chrome / Firefox |
| `npm run build` / `npm run build:firefox` | Сборка для Chrome / Firefox |
| `npm run zip` / `npm run zip:firefox` | ZIP-архив для Chrome / Firefox |
| `npm run compile` | Проверка TypeScript |
| `npm test` | TypeScript и модульные тесты |
| `npm run test:browser` | Браузерные сценарии |
| `npm run test:ui` | Проверки интерфейса |
| `npm run test:live -- --headed` | Проверка реальных поисковых сервисов |

Перед браузерными тестами выполните `npx playwright install chromium firefox`. Чтобы проверить одну платформу, добавьте `-- --chrome-only` или `-- --firefox-only` к команде браузерных или UI-тестов. Тесты используют отдельные профили.

Проверка реальных поисковых сервисов требует сети и готовых сборок обоих браузеров:

```sh
npm run build
npm run build:firefox
npm run test:live -- --headed
```
