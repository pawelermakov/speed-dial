# SpeedDial X

Новая вкладка с визуальными закладками для Chrome и Firefox. WXT, Vue 3, TypeScript и Tailwind CSS 4. Единственный источник URL, названий, категорий и порядка — стандартные закладки браузера. Dexie хранит только локальные изображения; настройки находятся в WXT Storage.

## Основная папка и категории

Папка-источник выбирается в **Настройки → Папка закладок** и применяется сразу с автоматическим сохранением. В списке доступны стандартные и пользовательские папки любого уровня с полными путями; управляемые и недоступные ветви исключены. Закрытие настроек сохраняет подтверждённый выбор. Смена источника ничего не создаёт, не переносит и не удаляет; массовой очистки папки в настройках нет.

Новый профиль автоматически использует системную **«Другие закладки»**, если её можно определить однозначно. Существующий сохранённый выбор, включая папку `Speed Dial`, остаётся прежним. Если папка стала недоступна, расширение переключается на однозначную «Другие закладки» с уведомлением либо предлагает открыть настройки. При неоднозначности аккаунтных/локальных корней нужен явный выбор. ID папки хранится локально и не включается в экспорт.

Прямые закладки основной папки относятся к виртуальной «Главной». Без дочерних папок панель категорий скрыта. Если есть только папки, пустая «Главная» не показывается: выбирается первая категория. Категории — только прямые дочерние папки; внутри показываются только непосредственные закладки. Более глубокие папки остаются в браузере и не отображаются. Реальная папка с названием «Главная» обозначается «Главная (папка)», её название в браузере не меняется.

Добавление, редактирование, удаление и перетаскивание плиток изменяют настоящие закладки браузера. Перенос между категориями доступен в форме редактирования. Создать категорию можно через контекстное меню страницы; при наличии категорий кнопка «+» справа от вкладок заменяется полем названия новой категории: Enter сохраняет её и возвращает «+», Escape отменяет без сохранения, а правый клик по реальной категории открывает меню «Изменить» / «Удалить» (также Shift+F10). «Изменить» заменяет вкладку полем с текущим названием: Enter сохраняет изменение, Escape возвращает старое название. Клик вне поля сохраняет непустое название, пустое отменяет редактирование; неизменённое название закрывает поле без записи. Поля названия растут и уменьшаются вместе с текстом. Перетаскивание вкладок категорий меняет их порядок. Изменения штатного менеджера и доставленной браузером синхронизации отражаются в открытых новых вкладках без перезагрузки.

## Изображения и синхронизация

Скриншоты и favicon — необязательные локальные Blob в IndexedDB, привязанные к строковому ID закладки и её URL. Изменение адреса исключает старые изображения из отображения. Изменение названия или перенос сохраняют кэш. Потеря/недоступность кэша не удаляет закладки. Фон новой вкладки хранится отдельно.

Без рабочего эскиза плитка сразу показывает домен на цветном фоне. Фон сохраняет оттенок favicon: яркие цвета автоматически затемняются, тёмные остаются исходными. Для всех сайтов применяется единый порог яркости; белая надпись имеет небольшую тень; если иконки нет или она не читается, цвет вычисляется по домену; размер однострочной надписи подстраивается под плитку, а длинные домены сокращаются многоточием. Полное название и адрес доступны в подсказке ссылки. На узком экране число колонок автоматически уменьшается, чтобы карточки оставались шириной около 140 px или больше; сохранённое число колонок задаёт верхний предел. Отсутствующие favicon запрашиваются без открытия сайтов: Chrome использует собственный `/_favicon/`, Firefox — доступные метаданные открытых вкладок; если браузер не знает иконку сайта, расширение пробует `/favicon.ico` на самом сайте. Стороннего сервиса favicon нет. Скриншоты автоматически массово не создаются. При добавлении захват можно включить явно; сначала сохраняется закладка, затем создаётся изображение. Ошибка захвата не теряет закладку. «Обновить эскиз» пробует независимо обновить скриншот и favicon, сохраняя заданный пользователем заголовок.

Захват временно открывает сайт **активной вкладкой** и сохраняет видимую область. Очередь сериализует снимки. Перед/после захвата проверяются активная вкладка, URL и загрузка; переключение пользователя отменяет снимок. Закрывается только созданная для захвата вкладка. Тайм-аут загрузки — 20 секунд, UI — 45 секунд с очередью. Закрытие новой вкладки отменяет захват. Недоступные сайты и редиректы могут не дать изображения. Принудительное завершение браузера может оставить временную вкладку.

Настройки показывают общий статус Chrome Sync через `identity.getProfileUserInfo({ accountStatus: 'SYNC' })`: включена / выключена / не удалось определить. Email и ID аккаунта не отображаются и не сохраняются. Это **не подтверждает**, что включена отдельная синхронизация закладок или завершена доставка изменений. Firefox показывает неподдерживаемый статус и предлагает проверить настройки браузера. `BookmarkTreeNode.syncing` используется только как подсказка расположения папки. Собственного сервера, OAuth и облачного хранилища расширения нет.

## Импорт, экспорт и безопасное удаление

Экспорт версии 2 содержит упорядоченный массив `entries`: закладки `{ title, url }` и категории `{ title, children: [...] }`, настройки и растровый фон. ID профиля, скриншоты, favicon и глубокие папки не экспортируются.

Импорт проверяет весь JSON до изменений: версия 2, один уровень категорий, HTTP/HTTPS без учётных данных, до 10000 закладок/10000 верхних элементов, названия до 4096 символов, JSON до 40 МБ, фон до 20 МБ. Импорт **добавляет** в выбранную папку и может создать дубликаты; настройки и фон применяются после добавления. Bookmarks API не предоставляет транзакций: при сбое сообщаются точные количества уже добавленных закладок и папок. Повторный импорт может снова добавить их. Старый формат `tabs` и автоматическая миграция Web SQL/localStorage не поддерживаются.

«Сбросить настройки и кэш» сохраняет браузерные закладки и выбранную папку. «Очистить выбранную папку» требует отдельного предупреждения о реальном удалении и возможной синхронизации. При скрытых вложенных папках очистка блокируется: используйте штатный менеджер. Удаление категории отдельно предупреждает об удалении **всех потомков**, включая невидимые. Другие ветви браузера не очищаются.

## Остальные возможности

Настройка «Показывать поиск по закладкам» включена по умолчанию; отключение скрывает поле и кнопку, а также выключает горячую клавишу `/`. Лупа справа от категорий открывает поиск по названию и URL в «Главной» и прямых дочерних категориях. Поле заменяет категории: 30% ширины окна на компьютере и вся ширина области закладок на мобильном; кнопка закрытия расположена внутри справа. Клик вне поля закрывает поиск, сохраняя фокус на выбранном элементе; клик по плитке оставляет выдачу до перехода. Высота панели сохраняется, включая переносы категорий. `/` открывает поле вне другого ввода, Escape закрывает его; пустая строка возвращает текущую категорию. Результаты обновляются при вводе; пустое состояние появляется после паузы 400 мс. Плитки в результатах сохраняют обычный вид и доступны для открытия и редактирования; перетаскивание в выдаче отключено. Поиск читает Bookmarks API и обновляется при внешних изменениях, не отправляя запросы в интернет.

В основной строке слева выбирается источник: Яндекс, Google, Кинопоиск, IMDb или MyShows. По умолчанию Яндекс; выбор сохраняется в настройках профиля и JSON v2. Смена источника сохраняет текст и отменяет старые подсказки. ArrowUp/Down выделяют пункт, Enter открывает выделенную подсказку или поиск; кнопка «Найти» всегда ищет исходный введённый текст. Кино-подсказки ведут на конкретные страницы выбранного каталога. Запрос отправляется только выбранному источнику, без cookies и сохранения истории.

**F04 выполнена:** реальные подсказки всех пяти сервисов проверены в Chromium MV3 без headless и Firefox. MyShows в headless Chromium возвращает 502 из-за User-Agent HeadlessChrome; для live-приёмки используйте `npm run test:providers:live:headed` без подмены User-Agent. Кинопоиск использует узкое Origin-правило для собственных POST SuggestSearch и один повтор временной GraphQL-ошибки в пределах общего тайм-аута. При отказе показывается «Подсказки временно недоступны», обычный поиск остаётся доступен. Cookies, авторизация и собственный прокси не используются.

Mail.ru с числом непрочитанных писем; ширина 50–100%, 2–12 колонок, расстояние 0–48 px, вертикальное центрирование, кнопка «+», пользовательский фон, контекстные меню и клавиатурный доступ сохранены.

Email передаётся только Mail.ru. Используются браузерные cookies без хранения паролей/токенов. Проверка происходит при загрузке и применении настроек; постоянного polling нет. При пустом email значка нет, при нуле бейджа нет, при отказе счётчик скрывается с пояснением. Реальная личная сессия Mail.ru тестами не используется; на результат влияют авторизация и ограничения cookies браузера.

## Установка и проверки

Node.js 22.12+ (проверено с 24.19.0), npm 10+.

```sh
npm ci
npm run dev
npm run dev:firefox
npm run compile
npm test
npm run build
npm run build:firefox
npm run test:smoke
npm run test:visual
npm run test:providers
# Live-проверка может завершиться с ошибкой при недоступности любого провайдера:
npm run test:providers:live
```

Chrome MV3: загрузите `.output/chrome-mv3` через `chrome://extensions`, режим разработчика. Firefox MV2 (140+): `about:debugging#/runtime/this-firefox` → временное дополнение → `.output/firefox-mv2/manifest.json`. Постоянная установка Firefox требует подписанного XPI. Архивы: `npm run zip` / `npm run zip:firefox`.

WXT берёт общие поля из `manifest.json` и добавляет браузерные разрешения через `wxt.config.ts`. В обеих сборках: `bookmarks`, `storage`, `tabs`, `unlimitedStorage`, `declarativeNetRequestWithHostAccess` (только правило Origin подсказок Кинопоиска), `<all_urls>` для текущего захвата/сетевых функций. Только Chrome: `favicon`, `identity`, `identity.email`. Дерево закладок и локальные изображения не отправляются сервисам расширения.

Smoke использует отдельные профили `.browser-test/`, Chrome for Testing из Playwright и Firefox с Marionette. Установить браузеры: `npx playwright install chromium firefox`. Отдельные платформы: `npm run test:smoke -- --chrome-only` / `--firefox-only`. Тесты не подключаются к личным профилям. Результаты игнорируются Git.

Визуальный тест заполняет Bookmarks API и кэш тестовыми данными. Desktop-сетки и Mail.ru сравниваются попиксельно со старыми эталонами Windows с учётом сдвига сетки из-за панели поиска; оформление текстовых плиток проверяется отдельным эталоном. Изменённые экраны сохраняются для просмотра с проверкой переполнения; поиск дополнительно проверяется на 360/1280/1920 px. Старые эталоны не заменяются автоматически.

Матрица фактических проверок и непроверенные ручные сценарии: [docs/verification.md](docs/verification.md). Никаких push, публикации, подписания, релизов и тегов эти команды не выполняют.

## Настройки и автосохранение (F05)

Панель сгруппирована: синхронизация, закладки, сетка, фон, почта, данные. Кнопки «Сохранить» нет: переключатели и папка применяются по change, числовые поля и email — после 275 мс валидного ввода или сразу при blur/закрытии панели. Неполный ввод не перезаписывает сохранённые значения. Разные поля обновляются отдельными patches под общим lock; вкладки получают подтверждённые изменения через Storage.watch. Неудачная запись откатывает только последнее изменение поля, ошибка с названием параметра остаётся видимой после закрытия. Импорт, экспорт и сброс остаются явными действиями; перед ними завершаются ожидающие записи.

Фон загружается отдельно от плиток: категории, источник и favicon не пересоздают его blob URL. Новое изображение сначала проверяется и декодируется, затем заменяет старое; есть видимая кнопка «Удалить фон». Сброс не удаляет закладки и не меняет выбранную папку.

Статус Sync проверяется при открытии и по кнопке «Проверить ещё раз», без polling и хранения данных профиля. При включённой синхронизации рядом с зелёным значком отображается доступный email аккаунта Chrome вместо слова «Включена»; он не сохраняется в настройках и экспорте. Общая синхронизация Chrome не гарантирует доставку закладок; в Firefox статус честно недоступен. Локальные скриншоты и favicon не синхронизируются.

`npm run test:settings` проверяет автосохранение, ошибки, вкладки, импорт/сброс и стабильность фона в Chrome/Firefox. Параметры общей прозрачности и оформления описаны в разделе F06 ниже.

## Глобальное оформление (F06)

В «Настройки → Оформление» доступны:
- Скругление 0–24 px (дефолт 5 px).
- Прозрачность поверхностей 0–50% (дефолт 20%; 0% означает непрозрачную поверхность).
- Размытие поверхностей blur(10px), по умолчанию включено.
- Цвет акцента #RRGGBB (дефолт #FFCC00) и иконка «Вернуть цвет по умолчанию» только для него.

Числовые поля и цвет показывают предварительный результат сразу, сохраняются существующим механизмом F05 с debounce/flush; checkbox сохраняется по change. Настройки включены в прежний JSON v2, старые профили получают безопасные дефолты. CSS-выражения в значении цвета не допускаются.

Единые CSS-токены задают поверхности, радиусы, границы, тени и состояния. Прозрачность применяется к подложкам; текст/иконки не выцветают, цветные плитки, скриншоты, favicon, пользовательский фон и фирменные цвета поиска не меняются. Blur применяется к стеклянным поверхностям и, при открытых настройках, к фону и основному содержимому. Для сложных фонов предусмотрены мягкие границы, автоматический цвет акцентной надписи и локальная подложка только когда она нужна для читаемости. Меню имеют строки от 40 px, мягкий hover от текущего акцента и различимый клавиатурный фокус. Forced-colors, reduced-motion и отсутствие blur имеют безопасные состояния.

`npm run test:appearance` проверяет настройки, матрицу светлого/тёмного/пёстрого фона, меню, доступность, автосохранение и сохранность брендовых цветов в Chrome/Firefox. Старые визуальные PNG не заменяются: общие изменения F06 просматриваются отдельно, защищённые пиксели текста и цветов F01 сравниваются с исходным эталоном.

Настройки: закреплённая шапка, прокрутка всей области под ней, числовые поля единого вида. Подсказки и размытие при открытии панели используют переход 250 мс; размытие фона и содержимого управляется uiBlur. Полосы прокрутки следуют акценту, служебные действия представлены иконками с подписями для доступности.

Типографика: единый Segoe UI/system-ui; основной текст, поля, кнопки, меню и поисковые подсказки — 16 px, вспомогательные подписи — 14 px. Hover-переходы — 250 мс. Плюс на плитке добавления — SVG до 56 px с адаптацией к размеру плитки, растровый newtab.png удалён.
